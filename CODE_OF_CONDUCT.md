# Code of Conduct

## Our commitment

We are committed to making participation in Ravi Kannada welcoming and respectful
for everyone, regardless of experience, identity, background, or ability.

## Expected behavior

- Be respectful, patient, and constructive.
- Welcome questions and explain technical decisions clearly.
- Critique ideas and code without attacking people.
- Respect privacy and avoid sharing another person's private information.
- Accept responsibility, apologize when appropriate, and learn from mistakes.

Harassment, discriminatory language, threats, personal attacks, sexualized content,
and sustained disruption are not acceptable in project spaces.

## Enforcement

Maintainers may edit or remove contributions that violate this code and may restrict
participation when necessary. Report conduct concerns privately through the contact
method in [SECURITY.md](SECURITY.md). If that method is unsuitable, contact a
repository owner privately through their GitHub profile. Reports will be handled as
confidentially as practical. Enforcement should be fair, proportionate, and focused
on protecting the community.

This code applies in repository spaces and when someone officially represents the
project. It is adapted from the principles of the Contributor Covenant 2.1.
