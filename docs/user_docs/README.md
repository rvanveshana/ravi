# Ravi Language Reference

Ravi is a Python-inspired programming language with Kannada, Kanglish, and English keyword profiles. It is designed to be readable, expressive, and practical for scripting, teaching, automation, and systems-oriented experiments.

Ravi supports dynamic values and optional static type annotations in the same language. Programs use `.rk` files, indentation, functions, collections, classes, modules, closures, exceptions, and a bytecode virtual machine.

## Start here

1. Read [What Is Ravi?](what-is-ravi.md).
2. Install the compiler with [Installation](installation.md).
3. Run the first program in [Getting Started](getting-started.md).
4. Learn the grammar from [Syntax](syntax.md) and [Keywords](keywords.md).
