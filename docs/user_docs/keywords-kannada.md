# Kannada Keyword Reference

Ravi is designed for Kannada-speaking developers. The current executable profile uses Kanglish spellings, which are Kannada words written with Latin characters. This page records the Kannada meaning and script alongside the runnable spelling.

| Purpose | Kannada meaning | Kannada script | Runnable Kanglish | English |
|---|---|---|---|---|
| if | ಒಂದು ವೇಳೆ | ಒಂದು ವೇಳೆ | `adre` | `if` |
| else | ಇಲ್ಲದಿದ್ದರೆ | ಇಲ್ಲದಿದ್ದರೆ | `illa` | `else` |
| while | ಇರುವವರೆಗೆ | ಇರುವವರೆಗೆ | `vargu` | `while` |
| for | ಪ್ರತಿಯೊಂದಕ್ಕೆ | ಪ್ರತಿಯೊಂದಕ್ಕೆ | `prati` | `for` |
| break | ನಿಲ್ಲಿಸು | ನಿಲ್ಲಿಸು | `nillu` | `break` |
| continue | ಮುಂದೆ ಸಾಗು | ಮುಂದೆ ಸಾಗು | `munde` | `continue` |
| function | ಕ್ರಿಯೆ | ಕ್ರಿಯೆ | `kriya` | `function` |
| return | ಕೊಡು | ಕೊಡು | `kodu` | `return` |
| try | ನೋಡು/ಪ್ರಯತ್ನಿಸು | ನೋಡು | `nodu` | `try` |
| except | ತಪ್ಪನ್ನು ಹಿಡಿ | ತಪ್ಪು | `tappu` | `except` |
| finally | ಕೊನೆಯಲ್ಲಿ | ಕೊನೆ | `kone` | `finally` |
| import | ತರು | ತರು | `tago` | `import` |
| from | ಇಂದ | ಇಂದ | `inda` | `from` |
| with | ಜೊತೆ | ಜೊತೆ | `jote` | `with` |
| class | ರೂಪ | ರೂಪ | `roopa` | `class` |
| and | ಮತ್ತು | ಮತ್ತು | `mattu` | `and` |
| or | ಅಥವಾ | ಅಥವಾ | `athva` | `or` |
| not | ಅಲ್ಲ | ಅಲ್ಲ | `alla` | `not` |
| in | ಅಲ್ಲಿ/ಒಳಗೆ | ಅಲ್ಲಿ | `alli` | `in` |

Kannada-script spellings are reference text today; use the Kanglish column in executable `.rk` files. This keeps the documentation honest while the Kannada-script lexer profile continues to evolve.
