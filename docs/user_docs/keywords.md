# Keywords

Ravi accepts the canonical Kanglish vocabulary by default and English equivalents in the English profile. The runtime currently uses these Latin-script spellings for executable source.

| Meaning | Kanglish | English |
|---|---|---|
| if | `adre` | `if` |
| elif | `inadre` | `elif` |
| else | `illa` | `else` |
| while | `vargu` | `while` |
| for | `prati` | `for` |
| break | `nillu` | `break` |
| continue | `munde` | `continue` |
| pass | `bidu` | `pass` |
| function | `kriya` | `function` |
| return | `kodu` | `return` |
| yield | `taru` | `yield` |
| try | `nodu` | `try` |
| except | `tappu` | `except` |
| finally | `kone` | `finally` |
| raise | `yese` | `raise` |
| import | `tago` | `import` |
| from | `inda` | `from` |
| with | `jote` | `with` |
| as | `aagi` | `as` |
| and | `mattu` | `and` |
| or | `athva` | `or` |
| not | `alla` | `not` |
| in | `alli` | `in` |
| is | `ide` | `is` |
| class | `roopa` | `class` |
| true | `true` | `true` |
| false | `false` | `false` |
| none | `none` | `none` |

The builtins `mudrisu`/`print` and `vidha`/`type` follow the selected profile. See [Kannada Keywords](keywords-kannada.md) for Kannada meanings and script references.
