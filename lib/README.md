# Ravi Kannada library sources

The `ravi/` directory contains the current source-library modules. Run repository
programs from the repository root so the loader can locate this directory.

See the [standard-library reference](../docs/user_docs/standard-library.md) for
available functions and readiness, and [module documentation](../docs/user_docs/modules.md)
for import syntax and loader limitations.

JSON, networking, and Kirana are blueprints. Contributors must implement and validate
an API before documenting it as available. Library delivery gates are in the
[development plan](../docs/development-plan.md).
